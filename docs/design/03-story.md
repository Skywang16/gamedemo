# 03 · 主线、剧情动画与心事件

## 1. 一句话

玩家收到祖母的信，来到停办灯夜的芦苇渡镇。一年里，玩家和镇民一起修好河灯台上的「六盏灯」，并在县里的**水库搬迁计划**面前，替小镇找到一个“留下来”的理由。三种结局，都是好结局。

完整的步骤表见 [14 · 主线全表](14-main-story.md)（由数据生成）；本文说明结构、规则和叙事方式。

## 2. 结构

| 部分 | 季节 | 标题 | 主旨 | 点亮 |
| --- | --- | --- | --- | --- |
| 序章 | 春 | 祖母的信 | 来到这里 | — |
| 第一章 | 春 | 灯夜重燃 | 从陌生人到邻居 | 一 · 桥灯 |
| 第二章 | 夏 | 留下的人 | 为什么有人愿意留下 | 二 · 钟灯、三 · 暖灯 |
| 第三章 | 秋 | 水从哪里来 | 一个人撑不住的事，全镇一起撑 | 四 · 渡灯、五 · 水灯；西尔维娅回到灯夜 |
| 第四章 | 冬 | 写给明年的信 | 面对改变，说出自己想要的生活 | 六 · 戏灯 |
| 终章 | 冬 28 日起 | 新的河灯 | 六灯齐亮，新的一年 | — |

共 **36 个步骤**（序章不算），**240 个场景**，其中主线与回应场景约 65 个，心事件 114 个，恋爱与婚礼场景 36 个，婚后事件 24 个。

### 2.1 步骤的规则

主线是一个阶段列表（`data/story.json` 的 `quests`）。每个步骤有标题、地点、提示，并可以有：

| 字段 | 含义 |
| --- | --- |
| `npc` / `station` | 由某位村民（找到他并交谈）或某处地点（桥、灯台、旧灯龛）触发 |
| `needs` | 要交出去的物品，交付时才扣 |
| `friendship` | 需要和某人达到的好感 |
| `available_day` | 最早哪一天可以完成：夏 1、秋 1、冬 1、冬 28 开启各章，章内的步骤没有日期限制 |
| `choice` / `flag` | 收尾时的选择，答案记入存档，影响后面的对白和结局 |
| `reward` | 金币和物品，随完成一起发放 |
| `lamp` | 完成后点亮第几盏灯 |
| `build` | 完成后农场多出一座建筑（温室） |

扣料、发奖励、推进阶段、记下选择同时提交，不会重复领奖；对白翻到第几页也一起保存，退出后接着读。错过日期不会卡关，只是要等。

### 2.2 六盏灯与它们带来的

灯亮的数量显示在 HUD 左上的六个小灯上，湖畔灯台上也会真的亮起。

| 灯 | 步骤 | 带来 |
| --- | --- | --- |
| 一 · 桥灯 | 桥的另一边 | 通往萤火湖畔 |
| 二 · 钟灯 | 钟声 | 钟楼每个整点（07:00–22:00）报时，敲几下就是几点 |
| 三 · 暖灯 | 温室开花 | 农场落成一座温室；**作物不再受季节限制**：种子摊卖全部种子，换季时不会枯萎 |
| 四 · 渡灯 | 修船 | 湖边渡口的船下水，可以乘船去**对岸 · 野渡** |
| 五 · 水灯 | 通水 | 水渠通水：**每天清晨所有田地自动浇好水** |
| 六 · 戏灯 | 剧院之夜 | 节日出席奖励翻倍（30 → 60 金币） |

## 3. 外部压力：水库搬迁计划

- **背景**：县里计划在下游修水库，缓解城区缺水和下游洪涝。蓄水后，芦苇渡所在的低地会被淹没。
- **推动者**：县规划办的维罗妮卡。她不是反派，真诚地相信搬迁更安全，手里的报告也是对的：镇上确实缺水，河运已衰，年轻人不断外流。
- **罗兹**：在县水利局参与勘测，同时是芦苇渡镇人，夹在两边之间；她提出“自己修一条水渠”。
- **主线问题**：不是“打败维罗妮卡”，而是“能不能替小镇拿出另一个办法，或者谈出更好的方案”。

罗兹和维罗妮卡在第一章完成之前一直在县里（日程是 `away`），之后回到镇上。

## 4. 选择与结局

所有选择都**不阻塞主线**，只留下标记，影响后面的对白、回应场景和结局。选择之后立刻播放一段回应场景。

| 标记 | 步骤 | 选项 |
| --- | --- | --- |
| `wish` | 灯夜重燃 | 留下 / 出发也有路回来 / 常常见面 |
| `leo_stay` | 行脚的客人 | 自由 / 一起过日子的人 / 值得慢慢做好的事 / 还不知道 |
| `wren_path` | 雷恩的信 | 想去就去 / 这里也需要你 / 我陪你 |
| `reservoir` | 陌生的来客 | 配合勘测 / 反对 / 第三条路 |
| `canal_route` | 水渠之议 | 沿河 / 穿过镇子 |
| `life_path` | 西尔维娅的问题 | 留下 / 偶尔出走 / 两样都要 |
| `theatre` | 剧院要拆 | 保留 / 搬迁 / 交给县里 |
| `meeting` | 小镇会议 | 留下 / 搬迁 / 折中 |
| `ferryman_heir` | 新的河灯 | 自己接 / 让波比学 / 托比再做几年 |

### 4.1 三种结局

小镇会议的选择完成时，游戏算出**结局**并记入存档（`ending`）。算法写在 `StoryRules.compute_ending`：

- **镇心** = 点亮的灯 × 10 + 听过的心事件数 + 参加过的节日数 × 3 + 对水库的态度（“第三条路” +10，“反对” +5）。
- 建议“搬迁” → **顺流**。
- 建议“留下”，没有表示配合勘测，且镇心 ≥ 70 → **原地生根**。
- 其余（折中，或想留下但镇心不够）→ **新岸**。

| 结局 | 内容 |
| --- | --- |
| 原地生根 | 县里撤销建库方案；水渠与河灯让小镇获得新的凝聚力；维罗妮卡申请调来做长期驻镇顾问 |
| 新岸 | 水库向下游移，低洼几户迁到新岸，镇中心保留；两处的人在灯夜把灯放进同一条河 |
| 顺流 | 全镇迁往上游新址，农场留作纪念地；人们带着河灯走到新地方 |

“最后一份报告”“年终宴”和“新的河灯”里，维罗妮卡与奥古斯都的台词、一年后的片段都按结局变化。

## 5. 摆渡灯人

灯夜的夜里，偶尔有人在对岸看见提灯的身影，镇上叫他“摆渡灯人”。真相在冬天揭晓：摆渡灯人不是鬼神，而是**摆渡人这一世代相传的职责**——灯夜之后，对岸有人把灯上的话读出来，送到该收信的人手里。托比做了五十年，一直没说。

- 第四章：打败旧采石矿里的守渠石像，打开封死的石室，西奥读出三百年的灯信，里面有西尔维娅年轻时写的那一封；乘船去对岸，托比在旧灯龛前说出真相。
- 终章：玩家决定谁来接下这份职责。

## 6. 剧情动画

每个场景都是一段全屏的小短片，由 `src/ui` 里的三个文件播放：`CutscenePaint`（背景与天气）、`CutsceneCanvas`（人物、镜头、特效）、`CutsceneView`（字幕、章节卡、按钮）。画面以 320×200 绘制，放大四倍显示，所以是和人物一致的像素风。

### 6.1 导演提示

数据里每一页是 `[说话人, 文字, 提示]`，提示是一个字典，写明这一页的画面变化；背景、气氛、特效、人物会一直保持到下一次改变。

| 提示 | 含义 |
| --- | --- |
| `bg` | 背景：farm 农场、town 小镇、market 集市、ranch 牧场、seaside 海边、forest 林地、lake 湖畔、greenhouse 温室、river 河边、shore 对岸、canal 水渠、stage 剧院、hall 议事厅、clock 钟楼内部、quarry 矿洞、vault 灯信库、inn 酒馆、shop 店铺、cottage 农舍、train 火车、feast 长桌宴 |
| `mood` | 气氛：day 白天、dawn 清晨、dusk 黄昏、night 夜晚、rain 雨、snow 雪 |
| `fx` | 特效：萤火虫、升起的灯、花瓣、雨、雪、落叶、尘土、彩纸、火星、蒸汽、钟声的光环、水光 |
| `actors` | 登场人物与站位（左、中、右七个位置）；新人物从两侧走进来，不在名单里的人走出去 |
| `act` | 一次性动作：跳起、点头、摇头、鞠躬、上前一步 |
| `sfx` | 音效：钟声、风铃、点灯、水声、欢呼、婚礼钟声、敲击、轰鸣、滴答 |
| `flash` / `shake` | 白 / 金 / 黑闪光；镜头震动 |
| `cam` | 镜头缓慢推近、拉远、左移、右移 |
| `title` | 画面中央的标题（如“一年后”） |
| `when` | 只在条件满足时显示这一页（某个选择的答案、结局、伴侣） |

### 6.2 播放的方式

- 台词逐字出现（按 E 或空格先显示完整句，再翻页）；说话的人轻轻点头。
- **章节卡**：每章第一个场景以黑底金字的卡片开场，按键可跳过。
- 换背景时画面淡出再淡入；灯亮的瞬间镜头闪金光；钟声、点灯、水声、欢呼都有真实的音效（`tools/audio/build_audio.py` 合成）。
- 所有心事件、恋爱与婚礼场景也是这样的小短片；没有专门写提示的页，按说话人的家（农场、酒馆、湖畔……）自动选背景，说话人自动登场。
- “减弱动态效果”开启时：台词立即显示，不推拉镜头，不闪光，不震动。
- 玩家自己（按创建角色的外观）也会站在画面里。

## 7. 心事件与恋爱

### 7.1 心事件

每位村民有自己的短剧情，好感达到门槛后在村民面板上出现“听听某某的故事”，读完得到回礼，每段只读一次。

- 可恋爱的 12 位：20 / 40 / 60 / 80 / 100，共 5 段，第 5 段是表白。
- 其余 18 位：30 / 60 / 90。
- 孩子和少年（米洛、波比、艾兹拉、克拉拉）只有友情。

### 7.2 从心意灯到婚礼

| 阶段 | 条件 | 发生什么 |
| --- | --- | --- |
| 恋人 | 第一章完成；好感 80 并听完前 4 段；一盏**心意灯**（杂货店 300 G） | 在村民面板点“递上心意灯”，播放一段场景，成为恋人 |
| 订婚 | 好感 100 并听完 5 段；一枚**同心环**（铁匠铺 3000 G） | 点“拿出同心环，求婚”，对方答应，三天后办婚礼 |
| 婚礼 | 订婚后第三天清晨 | 全屏婚礼：奥古斯都主持，誓词，戒指，一位朋友的祝福，钟声与花瓣 |
| 婚后 | 婚礼之后 | 对方搬进农舍；日程换成“住在农舍”的版本（早饭、上班、午饭回家、傍晚等你、晚饭、休息）；每天清晨为你做一件事；婚后一周和四周各有一段新的心里话 |

同一时间只有一位伴侣。不做“好感衰退”惩罚。人物的婚后日常和每天清晨做的事见 [02-cast.md](02-cast.md)。

## 8. 叙事风格

- 口语、克制，用具体细节写情绪（一块纸、一把锤、一碗汤），不直接说“难过”。
- 对白短句为主；每段场景 3–10 页；事件里的选项不超过 4 个。
- 每个人都有自己的小笑点（赛拉斯对野莓过敏、玛戈不爱胡萝卜、米洛的小鸡），防止整体过于感伤。
- 玩家称呼用“你”，不带性别；婚恋对象的对白对任何玩家适用。
