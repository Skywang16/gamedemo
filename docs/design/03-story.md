# 主线、抉择与结局

## 1. 一句话

玩家收到祖母的信，来到停办河灯夜的青苇镇；一年之内，玩家与镇民一起修复小镇的「六盏灯」，并在县里的**水库搬迁计划**面前，替小镇找到一个“留下来”的理由。

约 40 个阶段（阶段 0–40）。各阶段**没有日期惩罚**：节日按时发生，但错过某个任务只是对白略有不同，之后仍可补做。

## 3. 外部压力：水库搬迁计划

- **背景**：县里计划在下游修一座水库，缓解城区缺水和下游洪涝。蓄水后，青苇镇所在的低地将被淹没。
- **推动者**：县规划办的谢景明。他不是反派，他真诚地相信搬迁补偿更安全、更好，并且手里的报告是对的：青苇镇正在缺水，河运已衰，年轻人不断外流。
- **沈岚的位置**：沈岚在县水利局，参与勘测。她既是勘测的一员，也是青苇镇人，因此处在两边之间。
- **主线问题**：不是“打败谢景明”，而是“能不能为小镇拿出另一个办法，或者与县里达成更好的方案”。

### 镇心

隐藏数值，用来判定县里的最终决定，不显示数字，只在对白里体现：

- 修复的灯数（每盏 +10）
- 各人好感达到 6♥ 的人数（每人 +2）
- 完成的心事件数（每段 +1）
- 重要抉择中选择“让更多人参与”（每次 +5）
- 节日出席与参与（每个 +3）

## 6. 三种结局

结局由镇心与 C3、C6 共同决定。**三种都是“好结局”**，只是侧重不同，不设失败结局。

| 结局 | 条件概述 | 内容 |
| --- | --- | --- |
| A · 原地生根 | 镇心高，C3 选“反对”或“提出第三方案”，C6 选“留下” | 县里撤销搬迁；水渠与河灯使小镇获得新的凝聚力；谢景明主动请调为“长期驻镇顾问” |
| B · 新岸 | 镇心中高，C6 选“折中” | 水库选址向下游移动，低洼的几户迁至新建“新岸”，镇中心保留；青苇镇变成新旧交接的小镇 |
| C · 顺流 | C3 选“配合勘测”，镇心不论高低，C6 选“搬迁” | 全镇迁至上游新址，农场保留为纪念地；人们带着河灯走到新地方；结局充满温柔 |

每一种结局还会按玩家的恋爱对象、各人的 9♥ 事件、C1、C2、C5、C7，各自产出 2–4 段后续小片段（“一年后”）。

## 8. 苏青（祖母）与渡灯人

- 第一、二章：苏青只在信里出现。信件共 8 封，每封对应一个季节的关键节点，语气温和、不催促。
- 第三章：苏青在河灯夜（秋24）归来，不是“解决问题”，而是问玩家一个问题。
- 第四章：玩家在灯信库里读到苏青年轻时写给渡灯人的那盏灯。内容由 C7 的结果决定后续是否公开。

### 渡灯人（修订说明）

在 01-world.md 里渡灯人被写成“未知的传说”。本稿给出可落地的答案：

- **答案**：渡灯人不是鬼神，而是**摆渡人这一职责**。河灯夜之后，对岸有人把灯上的话读出来，送到该收信的人手里。镇上看到的“提灯的身影”，就是他们。
- **老橹**是最后一位；他年事已高，在第四章把这个责任交出来，是 C7 的来源。
- 这样“灯语”依然保留一点神秘，但其根源是**人的陪伴**，不是魔法。

## 9. 叙事风格

- **语气**：口语、克制，不用华丽辞藻；用具体细节写情绪（一块纸、一把锤、一碗汤），不直接说“难过”。
- **句式**：对白短句为主；每段事件 8–25 句。
- **互动**：事件里的选项不超过 3 个；每个选项都有简短但不同的回应。
- **幽默**：每个角色都有自己的小笑点（沈砚的过敏、米朵不爱胡萝卜、小满的小鸡），防止整体过于感伤。
- **性别中性**：玩家称呼用“你”；不使用带性别的称呼。婚恋对象的对白对任何玩家适用。
