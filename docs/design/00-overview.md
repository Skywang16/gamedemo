# 芽田农场 · 设计总览

芽田农场（Sprout Valley）是一款 Godot 4 / GDScript 的单机像素农场角色扮演游戏。玩家继承祖母在欧洲乡间小镇**芦苇渡镇**（Reedford）留下的农场，开荒、种地、钓鱼、做饭、养动物、下矿、结识三十位各有生活的村民，并和他们一起让停办的灯夜重新亮起来。

本目录是游戏的完整设计，每一份文档只写当前的设计，并与代码、数据一一对应。

## 2. 原创性约定

借鉴类型里通行的骨架（四季、节日、好感、送礼、钓鱼、采矿、烹饪、养殖），不复制任何同类游戏里的人物、名字、台词、剧情桥段、地名、物品名和数值表。所有人物、地名、剧情、物品文字和像素美术都是原创；美术由 Python / Pillow 代码逐像素绘制，没有使用现成素材包和图像生成模型。

本作主线是：**祖母的信 → 修好木桥、聚起大家 → 灯夜重燃**，长期故事线是**修复小镇的「六盏灯」并面对水库搬迁计划**。没有怪物，超自然成分只有“灯语”与“摆渡灯人”，见 01-world.md。

## 3. 设计原则

1. **没有反派**。冲突来自“每个人都以为别人不在乎”，外部压力（水库计划）的提出者也有他的道理。
2. **每个人是别人故事的一部分**。人物之间有明确的家庭、师徒、朋友、同事关系，任何一位的事件都会牵动别人。
3. **日常是主体**。村民真的会起床、走路、进店、上课、吃饭、回家，按星期、天气、节日和生日改变路线；店铺有营业时间；玩家的一天由种地、做饭、钓鱼、采集、送礼、赶路组成。
4. **没有惩罚**。错过任务不会卡关；晕倒、熬夜只会推进到第二天；选错工具不消耗资源也不弹教学提示，世界本身用画面和粒子反馈。
5. **数据驱动**。物品、作物、鱼、食谱、商店、动物、事件、日程、地图都是生成并校验过的 JSON，规则读数据，不在代码里写死内容。
6. **失败要明确**。外部数据（存档、设置、内容文件）一旦不合格就直接报错并说明原因，不静默修复，不做兼容回退。
7. **所有东西都可测**。规则是纯逻辑（可无窗口测试），日程、路线、天气、事件都是“种子 + 日期”的确定性函数。

## 4. 版本范围

当前版本是一个**可完整游玩的第一版游戏框架**：

- 完整的一年日历、节日、天气与季节外观；
- 全部玩法系统（农耕、采集、钓鱼、烹饪、养殖、矿洞、商店、升级、委托、图志）；
- 30 位村民的日程与关系系统，114 段心事件；
- 第一章「灯夜重燃」的完整剧情，从序章信件到灯夜心愿；
- 三个存档位、设置页、改键、减弱动态效果。

之后的扩展方向（不影响现有结构）：第二至第四章主线（钟灯、暖灯、渡灯、水灯、戏灯与水库搬迁计划的抉择）、婚恋与婚后生活、矿洞战斗、房屋升级、更多节日小游戏。这些在 03-story.md 与 04-systems.md 的“扩展方向”小节说明，现有数据格式（阶段列表、事件、日程规则、商店、物品）已为它们预留位置。
