# 05 · 美术规范与绘制流程

## 1. 方式

全部美术由 Python / Pillow 代码逐像素绘制，仓库里只有绘制工具和生成结果，没有任何现成素材包或图像生成模型。运行游戏不需要 Python；改美术时运行 `make art`，它会重新生成 `assets/art/` 和 `assets/ui/` 下的全部 PNG，再用 `make import` 更新 Godot 的导入文件。

绘制代码按类别组织：

```text
tools/art/
  terrain.py       室外地图背景（草地、路面、水岸、沙滩、洞窟地面）与装饰物绘制
  environment.py   树、杂草、木枝、石块、农舍与房屋屋顶配色、水井
  buildings.py     店面（杂货、铁匠、诊所、渔具、茶室）、三色民居、鸡舍、谷仓、灯塔、码头、矿车
  decor.py         围栏、路灯、花坛、树篱、木桶箱子、路牌、摊位、干草垛、饮水槽、岩石
  interiors.py     农舍、小酒馆、木工坊内景
  interiors2.py    杂货店、铁匠铺、诊所、茶室、渔具店内景
  characters.py    玩家与 30 位村民：4 方向 × 4 帧行走表、头像、发型与配饰
  actions.py       玩家七种工具动作的 4 方向 6 帧动作表
  crops.py         萝卜、胡萝卜的手绘阶段图，土壤，水壶
  produce.py       其余作物阶段图、作物 / 农产品 / 鱼 / 采集物 / 矿物 / 食物图标
  produce_build.py 批量输出上面的图标
  props.py         工具、收货箱、摊位、杂物
  enemies.py       旧采石矿的四种怪物（史莱姆、洞蝠、石偶、守渠石像），每种两帧
  interface.py     九宫格面板、按钮、滑块、开关、心形、图标、标题背景
tools/build_art.py 总入口
tools/audio/build_audio.py 用标准库合成剧情与战斗音效（钟声、风铃、点灯、水声、欢呼、婚礼、敲击、轰鸣、滴答、挥剑、受伤、击败）
```

## 2. 视觉方向

- **风格**：温暖、柔和、颗粒感适中的像素风；偏手绘水彩感的配色，避免纯饱和色。
- **格子**：32 像素；角色 32×48；头像 128×160；室内 30×19 格。
- **光源**：统一左上，阴影向右下。物体、建筑、树木、围栏都有接地阴影。
- **轮廓**：用同色相的深色，不用纯黑。
- **接地感**：建筑与地面之间有接缝草和阴影；人物脚底锚点统一，便于按脚底位置排序。
- **氛围**：昼夜渐变、季节与天气叠层、雨雪粒子、灯光光晕。

## 3. 人物

- 玩家：肤色 3 × 发色 3 × 衣服 4 × 是否戴草帽，创建界面实时预览，四方向行走表与八种工具动作（含挥剑）一致。
- 村民：每个人一份 `LOOKS`（肤色、发色、衣色、是否戴帽、配饰列表），由同一套分层绘制：身体 → 衣服 → 头发 → 帽 → 配饰。孩童身形缩小，长者用拐杖、披肩、眼镜、胡须等配饰区分。每个人的衣色、发型和配饰组合各不相同，缩小到 1 倍仍可辨认。
- 来宾西尔维娅与村民用同一套分层绘制，也有行走表和头像。
- 每人一张 128×192 的行走表（4 方向 × 4 帧）和一张头像；眼镜、胡须、领结、围裙等只在朝前的那一行绘制（背面与侧面不画）。
- 站定时轻微呼吸起伏，行走按方向切换行。

## 4. 环境

- **室外背景**：每张室外地图的背景由 `build_maps.py` 写出的地图数据烘焙成一张大图：道路、水域、树、装饰、碰撞来自同一份地图 JSON，所以“看到的”和“撞到的”一致。
- **生物群落**：草地（meadow）、沙滩（beach）、洞窟（cave）三套地面调色。
- **路面**：石板（镇、集市街）、土路（农场、牧场、林地、湖畔）、木栈道（海鸥湾）、压实土路（矿洞）。边缘有圆角和不规则缺口。
- **水岸**：水域由矩形组合，岸线有泡沫和碎石，水面有波光。
- **季节**：地图只烘焙一版（春季绿），季节由 `assets/shaders/season.gdshader` 在运行时只重映射画面里的绿色部分（草地、树冠）：夏更浓绿、秋橙黄、冬霜白蓝；道路、石头和建筑保持原色。换季前后几天按权重混合，季节之间平滑过渡。
- **天气**：`WeatherLayer` 在世界上叠加雨、雷雨（含闪电）、雪、大风（吹叶）和晴天的花瓣粒子；室内没有天气。全局色调由 `WorldAtmosphere` 按季节、天气和时间计算，18:00 起渐暗。
- **环境动画**：树冠与草丛轻摆、水纹、烟囱出烟、纸灯浮动、蝴蝶与花粉；“减弱动态效果”设置可关闭。

## 5. 剧情动画的画面

剧情场景的画面完全由代码绘制，不是预先画好的图片：

- **背景**（`CutscenePaint`）：21 种背景（农场、小镇、集市、牧场、海边、林地、湖畔、温室、河边、对岸、水渠、剧院、议事厅、钟楼内部、矿洞、灯信库、酒馆、店铺、农舍、火车、长桌宴），每种按 6 种气氛（白天、清晨、黄昏、夜晚、雨、雪）着色：渐变天空、日月星辰、远山近丘、树、房屋与亮灯的窗户、石板路、水面波光、湖畔灯台上点亮的灯、钟楼里转动的齿轮、水渠里流动的水……
- **特效**：萤火虫、升起的灯、花瓣、雨、雪、落叶、尘土、彩纸、火星、蒸汽、钟声的光环、水光，全部由时间驱动的粒子绘制。
- **灯光**：发光的物体（窗户、路灯、纸灯、矿晶）在气氛着色之后再绘一遍，所以夜里依然明亮。
- **人物**：使用同一张行走表，缩放与世界里一致；入场时按方向行走，说话时轻轻点头，另有跳起、点头、摇头、鞠躬、上前一步。
- **镜头**：整张画面按 320×200 绘制再放大 4 倍，推近、拉远、左右平移，闪光与震动都作用在整张画面上。

## 6. 物品与作物

- 63 种作物，每种 4 个生长阶段图 + 收获物图标 + 种子包图标。
- 65 种鱼、42 种采集物、22 种矿物、415 种食物各有独立图标；食物按菜式（汤、煎、烤、泥、果酱、派…）用不同的器皿造型，颜色取自主要食材。
- 图标统一 32×32，带高光与阴影，格子里一眼能分辨。

## 7. 界面

- 木框、纸面、九宫格面板、按钮的正常 / 悬停 / 按下 / 禁用四态、物品格、心形、金币、滑块与开关，都由 `interface.py` 绘制。
- 字体使用 Noto Sans SC（OFL 许可），许可文件在 `assets/fonts/OFL.txt`。
- 动画：面板进出场淡入 + 位移、金币数字滚动、标题页元素依次入场、屏幕淡入淡出与日卡；“减弱动态效果”开启时全部即时到位。
- 标题背景有云、水纹、炊烟和蝴蝶。

## 8. 质量门槛

出现下面的问题就返工：

| 问题 | 例子 |
| --- | --- |
| 平涂 | 大块没有光影变化的色面 |
| 僵硬对称 | 人物左右完全对称，像剪纸 |
| 锯齿与毛边 | 一像素的乱点、断线的轮廓 |
| 光向不一致 | 同一画面阴影朝向不同 |
| 接地感差 | 建筑 / 人物像贴在地上 |
| 识别度弱 | 缩小到 1 倍时分不出是谁、是什么 |
| 碰撞与画面不符 | 画着路却走不过去，画着墙却穿得过 |

每次改动美术后：`make art` → `make import` → 运行窗口测试抓取截图，逐张查看（`build/test-results/`）。
