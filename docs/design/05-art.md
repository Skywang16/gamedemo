# 05 · 美术规范与绘制流程

## 1. 方式

美术有两个来源，都只留下最终的 PNG 和生成它们的工具，没有任何现成素材包：

- **图像模型绘制**（建筑、地面贴图、树石杂草、街道装饰、室内家具）：由 `tools/art/ai_*.py` 调用图像生成接口（只用 GPT Image 2.5 系列），每次请求都带同一段风格提示词和同一张**风格板**（`assets/reference/interior_style_v1.png` 等版本固定的参考图），约束镜头、描边、配色；出图仍需逐张检查，参考图不等于一致性保证。精灵抠掉背景、裁边后统一走 `finish.py`（见下），再落在地图生成器约定的尺寸与锚点上。原始大图缓存在 `build/art-raw/`（不提交），已完成的 PNG 提交在 `assets/art/`；密钥从环境变量 `IMAGE2FREE_KEY` 或 `~/.config/gamedemo/image2free.key` 读取，不进仓库。
- **代码绘制**（人物与动作表、作物、图标、界面、怪物、工具、收货箱、摊位等小道具，以及室内的墙与地板、地毯、室外的路与水岸）：Python / Pillow 逐像素绘制，运行 `make art` 重新生成。`make art` 不会重画也不会删除图像模型绘制的那些 PNG（名单见 `tools/art/ai_*.py`）。

运行游戏不需要 Python；改美术后运行 `make import` 更新 Godot 的导入文件。

### 一格、一种像素、一套颜色

画面像素化的关键不是素材多精细，而是所有东西落在同一张网格上：

- **美术网格**：1 个美术像素 = 2 个游戏像素，一格地图（32 像素）= 16 个美术像素。人物、建筑、树、家具、地面都按这个颗粒绘制，混用 1 像素和 2 像素颗粒会让素材“不搭”。
- **一张地图一套调色板**：城镇、牧场、海边、室内等地图的素材吸附世界调色板 `assets/reference/world_palette.json`（160 色，`python tools/art/finish.py palette` 由已定稿素材重建），图像模型素材和地面、墙、地板全部用这一套颜色。农场的地形图块、地面装饰和物件出自同一张概念图，吸附到这组素材共同取出的农场调色板（128 色，`farm_tiles.py` 每次构建从素材组重新取色），保住概念图的青绿水面和嫩绿草地。没有“每件素材各自一套色”。
- **接地阴影**：站在地面上的东西（建筑、树、石头、装饰、家具）在底部留 4 像素，烘进一条硬边的接触阴影，光从左上来、阴影偏冷青。树干、家具腿、屋基都因此“坐”在地上。
- 以上由 `tools/art/finish.py` 统一提供（`grain` 颗粒与调色板、`shadow` 接地阴影、`ramp` 把地面贴图压成少数几个色调）；`imagegen.to_game` 对所有精灵调用它。

### 室内：搭建，而不是铺一张背景

星露谷的地图是瓦片分层搭出来的，不是一张画好的底图加贴纸；我们的室内也按这个方式组装（`room_kit.py`、`room_backgrounds.py`）：

- 地板连续铺设，同一房间、走廊、门洞共用一套木板（木地板竖铺，石板地用错缝石砖）。
- 地板北侧没有地板的格子，画两格高的**墙面**：顶部压条、墙纸、护墙板腰线、木护墙、踢脚线；其余与地板相邻的墙格画**墙顶**；两侧都是地板的格子是隔墙的顶。墙面不能压在地板上，隔墙必须留够两行（`Interior.check_walls` 在生成时报错）。
- 靠墙的地板有阴影；门洞两侧有门框线。
- 地毯按尺寸程序绘制，窗、画、挂架和门、楼梯是贴在墙面上的素材；家具保持独立 Y 排序精灵，站立类家具带接地阴影。
- 家具的源图在 `assets/library/interiors/`（提交的定稿），`room_assets.py` 把它们落到美术网格、世界调色板并加阴影，安装进 `assets/art/`。`ai_interior_library.py` 按固定参考图重新生成这批源图（4K 四件一张的素材板）。

### 提示词规则

- 统一镜头：经典 2D RPG 的俯视 3/4 视角，镜头约 30° 俯角；屋脊左右横向，只看见长长的檐下正面墙和被压扁的一带屋顶，不出现山墙三角、侧墙、等距菱形。
- 统一光与色：光从左上来，阴影偏冷青而不是黑；暖色、低饱和的故事书配色；深褐色 1 像素描边；扁平上色，每种材质两三个色阶。
- 每个提示词只描述一个孤立物体（或一排互相分开的物体），明确“无地面、无投影、无文字、无水印”。
- 地面贴图：正俯视，无透视、无光照渐变，要求硬边像素；缩到美术像素网格后，在网格里找边缘最吻合的窗口裁成无缝瓦片，不做混合；草地等平静的地面再去掉大块明暗、压成少数几个色调，细节由程序补草丛与小花。
- 室内：模型只画独立家具；墙与地板由 `room_kit.py` 搭建，`interior_layouts.py` 决定真实房间与通道。家具前脚锚点用于 Y 排序，碰撞只覆盖占地，不覆盖高出地面的画面。禁止重新生成一整张含家具背景后猜碰撞。

## 2. 视觉方向

- **风格**：明亮、温暖的硬边像素风：深褐色 1 像素描边，扁平上色，避免纯饱和色与柔和渐变。
- **格子**：32 像素（16 个美术像素，1 美术像素 = 2 游戏像素）；角色源帧 32×48、世界显示 40×60；头像 128×160；室内按用途为 24×20 至 40×28 等尺寸，家庭多房布局可到 32×38 格。
- **光源**：统一左上，阴影偏冷青、向右下。
- **轮廓**：用同色相的深色，不用纯黑。
- **接地感**：站立的物体底部带接触阴影，路与水岸有深色边线；人物脚底锚点统一，便于按脚底位置排序。
- **氛围**：昼夜渐变、季节与天气叠层、雨雪粒子、灯光光晕。

### 世界比例

- `ActorVisual.SCALE = 1.25` 统一玩家、村民与工具姿势，围绕脚底锚点绘制；源帧含透明留白，不能把帧高当作身体高度。普通成人可见身体约 41 像素（不含阴影），默认镜头下约 62 屏幕像素。
- 农场、林地、湖畔小路宽 2 格（64 像素），镇上主街、集市与牧场干道宽 3 格（96 像素）；广场、桥面和码头平台按用途保留空间，不机械套用道路宽度。
- 地面瓦片是 128×128 世界像素（4×4 格），农场的地面纹理周期是 256×256 世界像素（8×8 格）；石板与木板的纹样尺寸由瓦片决定，不使用模型原图尺寸。
- 显示倍率不放大世界坐标、脚部碰撞、工具作用距离或相机。动作与待机共用同一变换，浇水出水点同步变换，落点仍为目标格。
- 修改道路须同步重新生成地图 JSON 与室外背景，核对商店偏移门洞、路口衔接和所有出入口的可达性。

## 3. 人物

- 玩家：肤色 3 × 发色 3 × 衣服 4 × 是否戴草帽，创建界面实时预览，四方向行走表与八种工具动作（含挥剑）一致。
- 村民：每个人一份 `LOOKS`（肤色、发色、衣色、是否戴帽、配饰列表），由同一套分层绘制：身体 → 衣服 → 头发 → 帽 → 配饰。孩童身形缩小，长者用拐杖、披肩、眼镜、胡须等配饰区分。每个人的衣色、发型和配饰组合各不相同，缩小到 1 倍仍可辨认。
- 来宾西尔维娅与村民用同一套分层绘制，也有行走表和头像。
- 每人一张 128×192 的行走表（4 方向 × 4 帧）和一张头像；眼镜、胡须、领结、围裙等只在朝前的那一行绘制（背面与侧面不画）。
- 站定时轻微呼吸起伏，行走按方向切换行。

## 4. 环境

- **室外背景**：每张室外地图的背景由 `build_maps.py` 写出的地图数据烘焙成一张大图：道路、水域、装饰、碰撞来自同一份地图 JSON，所以“看到的”和“撞到的”一致。
- **农场**：分层 TileMap。地面（草地与林地）、开阔水面（4 帧动画）、泥岸、土路、地面装饰五层图块，按格子画的林地、土路、池塘自动拼出弯曲的边缘：路边一圈深色草边和伸进土里的草叶，北侧草沿在路面上投下阴影；池岸是一圈橙褐泥沿，远岸露出泥壁，近水一圈暗色；林缘的阴影落在草地上。林木、灌木、石墙、芦苇、睡莲与院子小物是独立的 Y 排序精灵，带接地阴影；碰撞与可耕地来自同一份 TMX。
- **生物群落**：草地（meadow）、沙滩（beach）、洞窟（cave）三套地面；草地以一种平静的草铺底，不贴大色块，只散落草丛与小花。
- **路面**：石板（镇、集市街）、土路（农场、牧场、林地、湖畔）、木栈道（海鸥湾）、压暗的土路（矿洞）。路由格子遮罩生成：圆角、一像素深色边线、外侧伸出的草叶；木栈道保持直角并带阴影。
- **水岸**：水域与碰撞格一致，岸线是深色外缘、泥岸、泛白的水边线，水面有短波纹，水心略暗。
- **季节**：地图只烘焙一版（春季绿），季节由 `assets/shaders/season.gdshader` 在运行时只重映射画面里的绿色部分（草地、树冠）：夏更浓绿、秋橙黄、冬霜白蓝；道路、石头和建筑保持原色。换季前后几天按权重混合，季节之间平滑过渡。
- **天气**：`WeatherLayer` 在世界上叠加雨、雷雨（含闪电）、雪、大风（吹叶）和晴天的花瓣粒子；室内没有天气。全局色调由 `WorldAtmosphere` 按季节、天气和时间计算，18:00 起渐暗。
- **环境动画**：树冠与草丛轻摆、水纹、烟囱出烟、纸灯浮动、蝴蝶与花粉；“减弱动态效果”设置可关闭。

## 5. 剧情动画的画面

剧情场景的画面完全由代码绘制，不是预先画好的图片：

- **背景**（`CutscenePaint`）：21 种背景（农场、小镇、集市、牧场、海边、林地、湖畔、温室、河边、对岸、水渠、剧院、议事厅、钟楼内部、矿洞、灯信库、酒馆、店铺、农舍、火车、长桌宴），每种按 6 种气氛（白天、清晨、黄昏、夜晚、雨、雪）着色：渐变天空、日月星辰、远山近丘、树、房屋与亮灯的窗户、石板路、水面波光、湖畔灯台上点亮的灯、钟楼里转动的齿轮、水渠里流动的水……
- **特效**：萤火虫、升起的灯、花瓣、雨、雪、落叶、尘土、彩纸、火星、蒸汽、钟声的光环、水光，全部由时间驱动的粒子绘制。
- **灯光**：发光的物体（窗户、路灯、纸灯、矿晶）在气氛着色之后再绘一遍，所以夜里依然明亮。
- **人物**：使用同一张行走表，尺寸按独立的 320×200 剧情舞台构图；入场时按方向行走，说话时轻轻点头，另有跳起、点头、摇头、鞠躬、上前一步。
- **镜头**：整张画面按 320×200 绘制再放大 4 倍，推近、拉远、左右平移，闪光与震动都作用在整张画面上。

## 6. 物品与作物

- 63 种作物，每种 4 个生长阶段图 + 收获物图标 + 种子包图标。
- 65 种鱼、42 种采集物、22 种矿物、415 种食物各有独立图标；食物按菜式（汤、煎、烤、泥、果酱、派…）用不同的器皿造型，颜色取自主要食材。
- 图标统一 32×32，带高光与阴影，格子里一眼能分辨。

## 7. 界面

- 木框、纸面、九宫格面板、按钮的正常 / 悬停 / 按下 / 禁用四态、物品格、心形、金币、滑块与开关，都由 `interface.py` 绘制。
- 字体使用 Noto Sans SC（OFL 许可），许可文件在 `assets/fonts/OFL.txt`。
- 动画：面板进出场淡入 + 位移、金币数字滚动、标题页元素依次入场、屏幕淡入淡出与日卡；“减弱动态效果”开启时全部即时到位。
- 标题背景有云、水纹、炊烟和蝴蝶。

## 8. 质量门槛

出现下面的问题就返工：

| 问题 | 例子 |
| --- | --- |
| 平涂 | 大块没有光影变化的色面 |
| 僵硬对称 | 人物左右完全对称，像剪纸 |
| 锯齿与毛边 | 一像素的乱点、断线的轮廓 |
| 光向不一致 | 同一画面阴影朝向不同 |
| 接地感差 | 建筑 / 人物像贴在地上 |
| 识别度弱 | 缩小到 1 倍时分不出是谁、是什么 |
| 碰撞与画面不符 | 画着路却走不过去，画着墙却穿得过 |

每次改动室内美术或布局后：`make maps` → `make art` → `.venv/bin/python tools/art/room_backgrounds.py --collisions` → `make test`。逐张检查 `build/interior-previews/` 的静态预览与碰撞叠图，再用窗口测试截图复查室内与室外。窗口测试使用隔离存档；不能以通路测试通过代替视觉检查。
