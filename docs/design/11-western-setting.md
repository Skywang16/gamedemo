# 11 · 西方乡村设定

## 2. 人名

- 31 个名字（含祖母西尔维娅）覆盖英、爱尔兰、法、德、意、瑞典、西班牙、尼日利亚等背景，体现一个多元的欧美小镇；英文原名见 [02-cast.md](02-cast.md)。
- **姓氏体现家庭**：卡弗家（Carver）、霍克家（Hawke）、弗林—霍尔沃森家（Flynn / Halvorsen）、奎尔家（Quill）、德尔加多家（Delgado）、布兰尼根家（Brannigan）、彭伯顿家（Pemberton）、阿什比家（Ashby）、惠特洛克家（Whitlock）。同一家庭同姓；收养、舅甥、姑侄的姓氏不同以体现关系。
- 称呼有昵称：罗兹（Rosalind “Roz” Carver）、多莉（Dolores “Dolly” Hawke）、托比（Old Toby Flynn）、安布罗斯医生（Dr. Ambrose Whitlock）。

## 4. 节日

灯夜（Lantern Night）是本地传统；其余节日取欧美乡村的常见形式：春耕日、风筝日、划船赛（regatta）、仲夏观星夜、丰收集市（harvest fair）、苹果酒日（cider day）、冬季集市（winter market）、浓汤日、剧院之夜、年终宴。日期与内容见 [01-world.md](01-world.md)。

## 5. 风貌

- 建筑：石砌与木构的小房子，红、蓝、棕、金四种屋顶，石板路、木栈道、铸铁路灯、栅栏与花坛。
- 铁匠铺、茶室、诊所、杂货店、渔具店各有独立的店面外观和室内陈设。
- 服装：围裙、背带衣、工装、白大褂、披肩、头巾、鸭舌帽、矿工灯、领结；配饰区分人物，见 [05-art.md](05-art.md)。
- 对话口吻：口语、简短、不使用中式俗语；玛戈的小酒馆、托比的渔具店这样的“人名 + 行当”命名是欧美小镇的习惯。
