# 一年里的特殊事件

主线与心事件之外，一年里还会发生一批“不在任务栏里”的事：有的随机出现，有的固定在某天，有的只在特定天气或条件下才会遇见。它们让日子有起伏，也让玩家愿意每天看一眼窗外。

本文所有事件为原创设计，不沿用任何同类游戏的具体事件。共约 **55 个事件 + 9 个节日小游戏**。

## 1. 规则

| 项目 | 约定 |
| --- | --- |
| 频率 | 夜间随机事件最多占三分之一的夜晚；同一天最多一个随机事件 |
| 避让 | 节日当天及前一晚、第一周、玩家结婚当天不触发随机事件 |
| 惩罚 | **无**。所有事件都可以无视，不会损失物品、好感或主线进度 |
| 奖励 | 小而有趣：稀有物件、图志条目、食谱、装饰、短时增益，不提供大额金币 |
| 一次性与可重复 | 标注“一次”的只触发一回，用标志位记录；标注“可重复”的有冷却时间 |
| 第二年起 | 一次性事件不再触发；可重复事件的概率略低，并加入少量“第二年版”变化 |
| 与主线关系 | 部分事件为后续章节提供线索，但不是必经之路；线索会在公告栏或余婶的八卦里再次出现 |

## 2. 夜间随机事件

玩家睡觉时发生，次日清晨由对白或画面告知；少数事件需要玩家当晚出门才能撞见。

| 事件 | 条件 | 内容与奖励 | 类型 |
| --- | --- | --- | --- |
| 河雾夜 | 春秋，阴天后的夜里，概率 8% | 湖面起白雾；当晚去湖畔会看见雾中摆渡的剪影，岸边捡到一页“灯信残页”（图志条目，集齐可兑换剧情） | 可重复 |
| 萤火潮 | 夏季，晴夜，概率 10% | 农场被成片萤火虫包围；次日随机三块作物升一档品质，出现“萤光”蝶 | 可重复 |
| 漂灯夜 | 春、秋，雨后第一夜，概率 8% | 一串不知从哪来的小灯顺水漂过；清晨岸边留下一盏，里面是一张匿名纸条（共 24 张，各是一个短故事） | 可重复，每张一次 |
| 白鹭落田 | 春夏，概率 6% | 一只白鹭在农场停留一夜；次日杂草与害虫减少，并给你一根白羽 | 可重复 |
| 夜梦 | 好感最高的角色事件刚触发或主线阶段变化后，概率 100% | 睡前进入一个短梦，共 12 段，揭示小镇过去的片段（摆渡人、旧河运、老戏台等） | 一次 |
| 霜花夜 | 秋末与冬季，气温骤降前一晚 | 未盖草的露天作物可能被冻伤；盖了草或种在温室的不受影响；清晨窗上有霜花可以“画”（小互动） | 可重复 |

## 3. 特别天气日

天气不只是背景，每种都带来一次“今天不一样”的体验。

| 天气日 | 条件 | 内容与奖励 |
| --- | --- | --- |
| 彩虹日 | 雨过天晴，概率 15% | 所有人走出屋子，在广场合影（小界面）；当天每位村民首次交谈的好感增益 +2 |
| 暴雨涨水 | 夏季连续雨天后，概率 6% | 河水上涨；渡口暂停；平时钓不到的深水鱼出现；暗渠入口封闭一天 |
| 大风日 | 春秋，概率 8% | 落叶、花瓣满屏飞；小满邀你去放风筝（小游戏），奖励一只风筝摆设 |
| 浓雾晨 | 春秋，概率 6% | 视野缩小；能听见远处钟声，但看不见钟楼；NPC 对白变为“起雾了”的版本 |
| 旱裂日 | 第三章起秋季旱日 | 土地龟裂，水壶效率下降；唐秀兰、周怀仁各有一段对白；水渠通水后此类天气不再出现 |
| 大雪日 | 冬季，概率 15% | 全镇的“雪人比赛”：在小学门口堆雪人，评比有小奖；打雪仗小游戏 |

## 4. 访客与流动摊位

| 访客 | 出现时间 | 内容与奖励 |
| --- | --- | --- |
| 行脚货郎（洛川） | 第二章前，每周日 | 稀有种子与摆设；洛川定居后改为日常商店 |
| 云游画师 | 春、秋各一次，随机一周 | 愿意为你的农场画一幅小画，挂在农舍；画面随你的农场布置变化 |
| 路过的老师傅 | 每季随机一天，镇口 | 教你一个特色食谱或手艺配方；每季一位，共四位 |
| 观鸟团 | 春秋候鸟季，各一周 | 林栖忙碌起来，湖畔有观鸟人；可与他们交换鸟类图鉴 |
| 糖画老人 | 冬季雪灯市前一周 | 在广场用热糖画图案，可以请他画一张你的“愿望糖画”，吃下后获得短时增益 |
| 河上商船 | 渡口修复（灯四）后，每月一次 | 唐秀兰的老同行带来外地特产；收购本地茶与鱼；只在晴天停靠 |
| 邮路特使 | 每季第一天 | 丁驰送来一封苏青的信，共 8 封，内容与四季变化呼应 |
| 灯下来客 | 春季，连续三天在门口放食物 | 一只流浪的猫或狗来到农场；玩家选择收养，成为农场宠物（可抚摸、会在特定天气做出反应） |

## 5. 农场突发

| 事件 | 条件 | 内容与奖励 |
| --- | --- | --- |
| 鸟群啄田 | 春夏，没有稻草人时，概率 6% | 一群鸟啄食成熟作物；稻草人（小满 9♥ 事件的礼物或自己制作）可防；若发生，当天可驱赶并得到“落羽” |
| 蜂群安家 | 夏季，概率 5% | 一群蜜蜂在农场一棵树上安家；可以请韩屿或池遥帮忙，也可以自己用烟囱引走，得到蜂蜜与蜂巢机器 |
| 野果发芽 | 秋季，概率 6% | 农场角落随机长出一棵野果树苗（桃、杏、柿其一） |
| 旧物浮现 | 大雨后，概率 10% | 一件埋在土里的旧物浮出地面：可能是老河运的铜牌、一只旧灯座或一页字条（图志条目） |
| 产崽日 | 有动物且好感达标时，概率 8% | 母鸡孵出一窝小鸡、母牛产犊；罗叔会来送上一句祝贺 |
| 雷击老树 | 雷雨天，概率 5% | 农场的某棵大树被雷击；留下“雷击木”（可制作稀有摆设）；全镇来慰问，小满偷偷问你“树会疼吗” |

## 6. 小镇突发

需要全镇人一起应对的小事。每件事都有“我来帮忙”和“交给别人”两种选择，不影响结果，但帮忙会让镇心略升。

| 事件 | 条件 | 内容与奖励 |
| --- | --- | --- |
| 屋顶漏雨 | 雨季，概率 7% | 某户镇民屋顶漏雨；沈砚在别处忙，请你送木板与钉子；帮忙者得到该户人家的一份谢礼 |
| 河堤决口 | 暴雨涨水之后，概率 4% | 全镇出动用沙包堵口，玩家参与“传沙包”小游戏；成功后，周怀仁在广场点名感谢 |
| 走失的牛 | 春秋，概率 5% | 罗叔的一头牛跑丢了；玩家根据线索（脚印、被踩的菜）找回 |
| 大扫除日 | 春天第一个周日 | 全镇人集合大扫除，玩家可选清理区域，获得“旧工具”与“怀旧小物” |
| 集市缺货 | 冬季，概率 5% | 季铭的货车晚到，请你顶一天；玩家体验当店员；得到一件店内折扣券 |
| 流感季 | 冬季，概率 8% | 一部分镇民生病；白芷与杜仲忙不过来，请你送草药；痊愈后会有小谢礼 |
| 邻里误会 | 余婶的八卦被误传，概率 5% | 两位镇民互相生气；玩家用对话与小礼物调解 |
| 钟声失准 | 钟楼修复后，概率 4% | 钟楼某天错乱敲响；顾远舟请你协助校准；会引出他父亲的一句旧话 |
| 迷路的孩子 | 春夏，概率 5% | 小满或小棠迷路；韩屿与玩家一同寻找；被找回后会有小心愿 |

## 7. 小节与季节活动

除了 9 个大节日，每个季节还有一个轻量的小节，只需在日程里看到、不需要特别准备。

| 小节 | 日期 | 内容 |
| --- | --- | --- |
| 风筝日 | 春 15 | 全镇在草坡放风筝；玩家可以参加“最高风筝”小比赛 |
| 荷塘夜话 | 夏 18 | 夜里在湖畔荷塘边聚会，聊天、放小灯，适合与任何角色深聊（给 1 次免费深谈） |
| 晒秋日 | 秋 18 | 家家把收成晒在门前，玩家可以去每家看一圈，得到各家的一份小物 |
| 腊粥日 | 冬 14 | 米朵在广场煮腊粥，玩家可以带食材来“加料”，全镇共享一锅粥；每种食材影响当天全体加成 |

## 8. 节日小游戏（9 个）

| 节日 | 小游戏 | 玩法与奖励 |
| --- | --- | --- |
| 开犁礼（春 8） | 翻地比赛 | 限时翻地，与阿禾、沈砚、池遥比；奖励一把“开犁礼”锄头外观 |
| 春灯（春 20） | 写灯 | 为一位镇民写一句话，次日灯影场景里会提到；奖励“春灯”装饰 |
| 龙舟赛（夏 12） | 节奏划船 | 与同队 NPC 同步节拍；队伍选择影响与谁关系更近；奖励龙舟模型 |
| 星河夜（夏 26） | 连星座 | 在夜空里用线连出 6 个“青苇星座”，每个星座对应一个镇上故事；奖励“夜空灯” |
| 丰收展（秋 9） | 展台评分 | 摆出作物、手工、料理，由评审（季铭、米朵、周怀仁）打分；奖励“丰收冠” |
| 河灯夜（秋 24） | 放灯 | 自由放灯，可写给人；次日触发灯影场景；奖励一盏“河灯台”小模型 |
| 雪灯市（冬 9） | 摆摊 | 摆一天摊位，与 NPC 交换礼物；奖励雪灯 |
| 戏台夜（冬 18） | 配戏 | 在乔月的戏里扮演小角色，台词选择决定戏的结尾；奖励“戏台票” |
| 岁末席（冬 28） | 席间回顾 | 席间每位角色讲一句年度话，玩家可回应；回应影响终章对白 |

## 9. 隐藏与稀有事件

这些事件不会在任务栏出现，甚至没有明确提示，靠观察和耐心触发。

| 事件 | 触发 | 内容 |
| --- | --- | --- |
| 孟奶奶的灯 | 好感 3♥ 之后，每年河灯夜前的雨夜 | 三段隐藏小谜：她总在同一时间放一盏灯，没人知道写给谁 |
| 古井回声 | 暗渠探到第 20 层之后 | 农场古井里传来水声与一段歌，指向暗渠的一处入口 |
| 老橹的深夜渡 | 渡口修复后，夜里 23 时之后遇见老橹 | 他撑船带你去对岸一个玩家平时去不了的小岛；奖励一件摆渡人的旧物 |
| 钟楼的第十三声 | 钟楼修复后，在某晚午夜整点前后站在广场 | 钟楼多敲一声，打开阁楼；里面是周怀仁父亲的日记 |
| 苏青的三封未寄之信 | 农舍地板下，调查床底三次 | 三封苏青年轻时写而没寄出的信，内容分别写给渡灯人、周怀仁、孟奶奶 |
| 水下的灯 | 第三章旱季湖水降到最低时 | 湖心露出一座旧灯台；可以走过去点亮，是图志的特殊条目 |
| 匿名灯 | 第一、二章每月一次 | 河灯台前每月多出一盏匿名灯；第四章揭晓是孟奶奶托老橹放的 |
| 雪夜山影 | 冬季雪夜，概率 3% | 山坡上出现一只白色大鹿的剪影；靠近则消失；成功记录进图志后得到“白鹿角挂饰” |

## 10. 周期与纪念事件

| 事件 | 触发 | 内容 |
| --- | --- | --- |
| 生日 | 每位角色一个生日 | 当天人物位置固定，有专属对白；礼物好感翻倍；可恋爱角色在 6♥ 之后会有“庆生小场景” |
| 到镇纪念 | 每 112 天（一年） | 一封苏青的信，以及一份小镇“年度回顾”（镇上变化清单） |
| 季末小结 | 每季最后一天夜里 | 周怀仁在广场宣读本季发生的事，以对白形式反映镇心，无数字 |
| 玩家的生日 | 创建角色时可选 | 当天每位镇民来送一份小礼物；每年一次 |

## 11. 数据与实现要求

| 项目 | 约定 |
| --- | --- |
| 位置 | `data/events/world/<id>.json`，每个事件一个文件 |
| 字段 | `id`、`kind`（night / weather / visitor / farm / town / minor_festival / hidden / periodic）、`trigger`（季节、日期、星期、天气、概率、前置标志位、主线阶段）、`cooldown`、`once`、`scene`、`rewards`、`flags` |
| 规则层 | `src/story/event_rules.gd` 统一在每天结算时根据触发条件抽取事件，保证“一天最多一个随机事件”“避让节日”的规则 |
| 存档 | 记录已触发的一次性事件、冷却剩余天数、随机种子 |
| 测试 | 每个事件至少一条能够触发的路径；冷却与概率可确定地重放；奖励物品在物品表中都存在；节日避让规则成立；第二年一次性事件不再触发 |
| 美术 | 每个事件需要的专属画面（雾、萤火、风筝、雪人、白鹭、白鹿剪影等）列入 05-art.md 的特效与天气清单 |
