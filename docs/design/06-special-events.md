# 06 · 节日与每日小事

一年里有两类“不在任务栏里”的事：**固定日期的节日和小节**，以及**清晨随机发生的小事**。它们让日子有起伏，也让玩家愿意每天看一眼窗外。

## 1. 原则

| 项目 | 约定 |
| --- | --- |
| 惩罚 | **无**。所有事件都可以无视，不会损失物品、好感或主线进度 |
| 奖励 | 小而有趣：一点物品、金币、作物生长或好感，不提供大额金币 |
| 频率 | 每天清晨最多一件随机小事；第一周、节日当天不发生 |
| 确定性 | 是否发生、发生哪件，是“世界种子 + 日期”的纯函数，可重放、可测试 |
| 记录 | 小事发生时清晨有提示，日卡会写出一句话；奖励物品进入图志 |

## 2. 节日（9 个）与小节（4 个）

日期、内容和固定天气见 [01-world.md](01-world.md)。节日当天：

- 村民 09:00 起去小镇广场，在 40 个预设站位中各占一格，按下午、傍晚的行程继续（回家、吃饭、看灯）；
- 所有店铺 09:00–14:00 关门；
- 玩家 09:00–14:00 进入小镇广场就自动参加：金币 +30（点亮戏灯之后 +60），所有村民好感 +2；每年每个节日只算一次，记在存档的 `festival_done` 里；
- 日卡写出“今天是某某节”，HUD 日历悬停可看下一个节日。

## 3. 清晨小事（20 种）

触发条件由“季节、当天天气、前一天天气、概率”组合，数据在 `data/events.json`，规则在 `src/gameplay/event_rules.gd`。

| 小事 | 条件 | 概率 | 内容 |
| --- | --- | --- | --- |
| 河雾夜 | 春秋，前一天阴 / 雨 | 8% | 岸边留下一页灯信残页 |
| 萤火潮 | 夏，前一天晴 | 10% | 农场被萤火虫包围，3 株作物多长一天，得到萤火虫 |
| 漂灯夜 | 春秋，前一天雨 | 10% | 一串小灯漂过，岸边留下匿名字条 |
| 白鹭落田 | 春夏 | 6% | 白鹭留下一根白羽 |
| 霜花夜 | 冬 | 8% | 院角探出一朵雪花莲 |
| 彩虹日 | 晴，前一天雨 / 雷雨 | 15% | 所有村民好感 +2 |
| 风吹来的花 | 大风 | 25% | 2 朵报春花 |
| 雷击老树 | 雷雨 | 20% | 6 块木材 |
| 蜂群安家 | 夏 | 5% | 3 罐蜂蜜 |
| 野果落地 | 秋 | 6% | 3 个野苹果 |
| 旧物浮现 | 前一天雨 / 雷雨 | 10% | 一枚旧铜币 |
| 鹌鹑窝 | 春 | 5% | 2 颗鹌鹑蛋 |
| 雪天的红果 | 下雪 | 20% | 2 颗冬青果 |
| 雨后蘑菇 | 秋，前一天雨 | 30% | 3 朵蘑菇 |
| 冲上岸的鲶鱼 | 夏，雷雨 | 25% | 一条鲶鱼 |
| 云游画师 | 春秋 | 4% | 画师为农场画了张速写，付你 80 金币 |
| 屋檐下的燕巢 | 春 | 5% | 一根细羽 |
| 邻居的篮子 | 任意 | 6% | 门口放着 3 颗野莓 |
| 清晨露水 | 春，晴 | 10% | 2 株作物多长一天 |
| 秋风送礼 | 秋，大风 | 20% | 3 颗榛子 |

当天若有多件小事满足条件，按种子打乱顺序后第一件通过概率的发生。
