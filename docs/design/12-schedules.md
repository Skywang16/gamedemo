# 12 · 日程系统

每位村民有自己的生活节奏：每天几点起床、去哪里、做什么、几点回家；周一到周日不同，四季不同，天气不同，节日和生日不同，第二年起、剧情推进后也会变化。村民在地图上真的**走路**，会进出建筑、跨地图、避开障碍。每个人每天的完整行程见 [13-routines.md](13-routines.md)（由数据生成，与游戏一致）。

## 1. 时间制度

| 项目 | 约定 |
| --- | --- |
| 一天 | 06:00 开始，26:00（次日凌晨 2 点）强制休息；钟面在 24:00 后显示 00:00、01:00 |
| 时间流速 | 现实 7 秒 = 游戏 10 分钟，一天约 14 分钟 |
| 一周 | 周一到周日，每季 4 周，每年 16 周 |
| 一年 | 4 季 × 28 天；春 1 日是周一 |
| 昼夜 | 18:00 起渐暗，22:00 后为深夜；24:00 起提示“很晚了”，26:00 昏睡后在床上醒来，没有惩罚 |

## 2. 日程规则

每个人有一份**有序规则列表**。每天开始时，按顺序找第一条条件全部满足的规则，用它的行程。最后一条规则没有条件，作为日常行程。

| 条件 | 含义 |
| --- | --- |
| `birthday` | 今天是这个人的生日 |
| `festival` | 今天是节日 |
| `weekdays` | 星期几（0 周一 … 6 周日） |
| `week` | 一季的第几周（1–4），用于“每月第一个周六”之类 |
| `seasons` | 春夏秋冬 |
| `weather` | 晴、阴、雨、雷雨、大风、雪 |
| `days` | 一季中的第几日 |
| `year_min` / `year_max` | 第几年 |
| `stage_min` / `stage_max` | 主线阶段（用于“某人从第一章结束后才出现”） |

编写时的顺序惯例是：**生日 → 节日 → 剧情 / 年份特例 → 天气 → 季节与星期的组合 → 周末 → 平日 → 日常**；由于先匹配先生效，越特殊的越靠前。

### 2.1 行程写法

一条行程是若干“**到达某地的时刻 · 地点 · 在做什么**”：

```text
06:30 market/home_24 | 起床
09:00 market/stall_c | 摆摊
12:30 market/plaza_w | 午休
```

- 第一条是这一天的起点（起床的地点，通常是家门口，隐藏），时刻不早于 06:00；午夜到第一条之间村民就待在起点。
- 时刻必须严格递增，范围 06:00–26:00（25:00 表示凌晨 1 点）。
- 地点是“地图/名称”，名称来自 `tools/world/places.py`；`festival` 是节日广场站位；`away` 表示不在镇上（这条规则只能有这一条行程）。
- 隐藏地点（门口）：走到那里就进屋，进屋后不绘制，直到下一个地点。

## 3. 走路

| 项目 | 约定 |
| --- | --- |
| 路线 | 在每张地图的可通行格上做寻路；跨地图时先走到出口，在另一张地图的入口继续走 |
| 速度 | 每游戏分钟 2 格；每过一道门多算 1 分钟 |
| 出发时间 | **按到达时刻倒推**：路程要 20 分钟，就提前 20 分钟出发；来不及就立即出发并迟到 |
| 路上 | 显示“正在路上”，朝行走方向行走，有 4 方向 × 4 帧行走动画 |
| 站定 | 面朝下，有轻微呼吸起伏 |
| 桥 | 修桥之前（主线阶段 < 3），小镇与湖畔之间没有路线；住在湖畔的人只在湖畔活动 |
| 节日 | “festival”地点会按村民的编号分配广场上的 40 个站位之一，同一时刻不会重叠 |

玩家看到的村民位置，永远是“按当天日程和当前时间推出来的”：读档、换地图、睡一觉再回来都一致，不需要保存村民位置。村民可以交谈的前提是在当前地图上可见；在屋内（隐藏地点）时看不到，也无法交谈。

## 4. 营业时间

商店只在营业时间开门，店主在柜台后；关门时门打不开，并提示营业时间。

| 商店 | 营业 | 休息日 |
| --- | --- | --- |
| 黑兹尔的种子摊 | 08:00–18:00 | 无 |
| 霍克杂货店 | 09:00–17:00 | 周日 |
| 布兰尼根铁匠铺 | 09:00–17:00 | 周日 |
| 芦苇渡诊所 | 09:00–17:00 | 周日 |
| 托比渔具店 | 06:00–18:00 | 无 |
| 草溪牧场 | 08:00–17:00 | 无 |
| 卡弗木工坊（建造台） | 09:00–17:00 | 周日 |
| 铜壶茶室 | 10:00–22:00 | 无 |

雨天商店照常营业。节日当天，商店在 09:00–14:00 关门，店主去参加节日。

## 5. 日程里的节奏

数据里实际使用了这些变化（统计自 30 位村民的 194 条规则）：

| 变化 | 例子 |
| --- | --- |
| 星期 | 平日工作上学，周末摆摊、休息、逛集市；周日许多店关门 |
| 天气 | 雨、雷雨、雪天，村民改在室内活动（黑兹尔在雨棚下分种子，赛拉斯在木工坊刨窗框） |
| 季节 | 西奥暑假前后的路线不同；第一章之后梅芙夏秋常去海边 |
| 第几周 | 每季第 4 周的周日，费利克斯去镇公所清点钟楼零件，格雷戈尔在杂货店盘存 |
| 第几年 | 第二年起：朱妮带克拉拉学习；诺拉的茶室开出第二个柜台；艾兹拉正式出师；克拉拉去外地读书，周日才回来 |
| 剧情阶段 | 第一章完成前，罗兹、维罗妮卡在县里；利奥平日不在镇上，只有周末摆摊；雷恩在桥修好之前只在湖畔，之后节日和周日才会去小镇 |
| 生日 | 当天有专属行程，多半在人多的地方过生日 |
| 节日 | 九点去广场，下午分头活动，傍晚聚餐，晚上回家 |
