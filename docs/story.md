# 芽田农场：第一章「灯夜重燃」

全部人物、家庭、长期故事线和心事件见 [design/03-story.md](design/03-story.md) 与 [design/02-cast.md](design/02-cast.md)。本文是第一章的实现规格。

## 体验目标

一段可完成、没有倒计时惩罚的开篇：玩家从陌生住客变成参与小镇生活的人。种田提供第一次贡献，采集提供材料，修桥改变地图通路，结尾由玩家亲自选择一个愿望。完成后继续经营。

## 阶段与任务

| 阶段 | 目标 | 内容与奖励 |
| --- | --- | --- |
| 序章 祖母的信 | 在农舍自愿阅读 | 选“好好照料这片土地”或“重新开始”，保存为初始心愿，不阻塞主线 |
| 0 新邻居 | 与黑兹尔交谈 | 欢迎与引导 |
| 1 一顿饭的距离 | 交给玛戈 2 份萝卜 | 玛戈提起停办的灯夜；+20 金币 |
| 2 桥的另一边 | 4 木材、3 石料交给赛拉斯 | 修好镇东木桥，湖畔开放；只扣一次材料 |
| 3 湖边的记录员 | 到湖畔与雷恩交谈 | 读到祖母留下的手记 |
| 4 请大家再聚一次 | 3 份野莓、2 份萝卜交给玛戈 | 聚餐准备好 |
| 5 灯夜重燃 | 在湖畔灯台读群像对白并选择愿望 | 三个愿望改变尾声文字；+50 金币，章节完成 |
| 6 灯亮之后 | 自由经营 | 村民换成“灯夜之后”的台词，罗兹、维罗妮卡回到镇上 |

材料来源：萝卜四季都能种；木材、石料、野莓在松木林有固定采集点，也可以靠清理农场荒地得到。任务没有日限，也不会因为卖掉了作物而卡住。

## 规则约定

- 对白逐页显示，翻到第几页随存档保存；退出对话不领奖励，下次从当前页继续。
- 完成条件在 `StoryRules.complete` 里再次核验；扣料、发奖励、推进阶段同时提交，同一阶段不能重复领奖。
- 主线只检查所需材料，不检查玩家是否做过教学步骤。
- 地图锁（桥未修好时湖畔不可进）在规则入口和交互入口同时生效，存档校验也拒绝桥未修好时在湖畔的存档。
- 阶段数据在 `data/story.json` 的 `quests`，场景在 `scenes`，由 `tools/content/story_data.py` 生成。
