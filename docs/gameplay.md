# 芽田农场：玩法说明

## 第一天

1. 创建姓名、农场名、肤色、发色、衣服和帽子，选一个存档位，直接进入农场。祖母的信放在农舍桌边，可以自愿阅读。
2. 屋前找黑兹尔，按 E 交谈。农场最初只有草地、杂草、木枝、石块和树木，没有翻好的田。
3. 5 镰刀清草、6 斧头清理木枝和砍树、7 镐清理石块。鼠标点击身边一格，或按空格对面朝方向使用工具。清理得到纤维、木材、石料。
4. 清出地后，1 锄头翻土、2 播种、3 水壶浇水、4 收获。Q 切换种子。萝卜 3 天成熟，胡萝卜 4 天；不浇水的日子不生长。
5. 在农场南边的路口进入小镇；玛戈的小酒馆、赛拉斯的木工坊、告示板都在那里。J 打开手记查看下一步，M 打开地图。
6. 晚上回农舍，在床边按 E 或在 Esc 菜单点“回家休息”睡觉；第二天在屋里醒来。

## 操作

| 键 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 跑步（可在设置里改为切换式） |
| E | 交谈、进出房门、采集、打开柜台和灶台 |
| 空格 / 鼠标左键 | 使用当前工具 |
| 1–9 | 锄头、种子、水壶、收获、镰刀、斧头、镐、钓竿、长剑 |
| Q | 切换当季种子 |
| B | 背包（物品分类、吃东西、储物箱存取） |
| J | 故事手记 |
| M | 地图册 |
| Esc | 暂停菜单 / 关闭面板 |

移动、互动、使用工具、跑步、切换种子、手记、地图、背包可以在设置里改键；Esc 和 1–9 固定。

## 一天的节奏

- 一天从 06:00 到 26:00，现实约 14 分钟；菜单和对话暂停时间。24:00 之后提示该睡了，26:00 会昏睡并回到床上。
- 右上角显示日期、星期、天气、时间和金币；鼠标悬停可看明日预报、今日节日、生日和下一个节日；右侧竖条是体力。
- 村民按各自的日程走路、上班、吃饭、回家；商店有营业时间，周日许多店休息；节日 09:00–14:00 全镇都去广场，店铺关门。每个人的完整日程见 [design/13-routines.md](design/13-routines.md)。
- 雨、雷雨、雪会在清晨自动浇灌所有作物；换季时不适合新季节的作物会枯萎，耕地保留。

## 能做的事

- **种地**：63 种作物按季节生长，部分可反复收获；种子在种子摊和杂货店按当季出售。
- **采集**：松木林、湖畔、海滩每天刷新采集点，按季节出产野菜、蘑菇、坚果、贝壳等。
- **钓鱼**：8 键拿钓竿，面对 3 格内的水按空格抛竿；浮标沉下去再按空格提竿，然后在绿区里按空格。水域有池塘、溪流、河、湖、海、洞窟，鱼随季节、天气和时段出没。托比渔具店可升级鱼竿。
- **烹饪**：农舍和小酒馆的灶台，411 个食谱，做得越多等级越高；食物恢复体力、可出售、可送礼。
- **养动物**：在木工坊建鸡舍和谷仓，在牧场买动物，每天喂干草、抚摸、收取蛋奶毛。
- **下矿与战斗**：松木林北边的旧采石矿共三层，敲矿点得矿石，拿到铁匠铺熔炼成锭，升级工具。矿洞里有史莱姆、洞蝠、石偶，第三层深处有守渠石像；按 9 拿剑，空格挥剑；被打倒只会被抬出洞口，不丢东西。
- **社交与恋爱**：每天交谈、送礼，好感达到门槛后听村民讲自己的故事。第一章完成后，12 位村民可以发展恋情：好感 80 送心意灯成为恋人，好感 100 用同心环求婚，三天后举行婚礼，之后对方住进农舍，每天清晨为你做一件事。
- **委托**：小镇告示板每周 4 份委托，交付得到金币和好感。
- **图志**：背包里取得过的所有东西都会记入收集册。
- **随机小事与节日**：见 [design/06-special-events.md](design/06-special-events.md)。

## 主线

序章的信之后是四章加终章，共 36 个步骤，每一步都是一段全屏剧情动画：

- **第一章 灯夜重燃（春）**：新邻居 → 一顿饭的距离 → 桥的另一边 → 湖边的记录员 → 请大家再聚一次 → 灯夜重燃。
- **第二章 留下的人（夏 1 日起）**：修好钟楼，建温室，听雷恩的信，回答利奥的问题。
- **第三章 水从哪里来（秋 1 日起）**：湖水下降，县里来了水库搬迁计划，修船，开渠，西尔维娅回到灯夜。
- **第四章 写给明年的信（冬 1 日起）**：打败旧采石矿的守渠石像，读灯信库里三百年的灯信，托比说出摆渡灯人的真相，剧院之夜，全镇开会。
- **终章 新的河灯（冬 28 日起）**：年终宴，放最后一盏灯，看一年后的小镇。

六盏灯每点亮一盏，游戏就多一项改变：通湖畔、钟楼报时、全年耕作的温室、对岸的渡口、每天自动浇水的水渠、节日奖励翻倍。结局由你在小镇会议上的选择和小镇的“心”共同决定。详见 [story.md](story.md) 与 [design/03-story.md](design/03-story.md)。

剧情场景里按 E 或空格：先显示完整的一句，再翻页；章节卡可以按键跳过。

## 存档与设置

- 三个存档位。标题的“继续生活”读最近一次的存档；“读取存档”可读取或删除；“开始新生活”创建角色后选择存到哪个位置。
- 自动保存每 30 秒及关键操作后进行（设置里可关），Esc 菜单可手动保存、保存并返回标题、保存并退出。
- 设置分四页：声音、画面（全屏、垂直同步、减弱动态效果）、操作（改键）、游戏（自动保存、切换式跑步、互动提示）。设置存在独立的 `settings.json` 中，文件不合格时本次使用默认设置并提示。
