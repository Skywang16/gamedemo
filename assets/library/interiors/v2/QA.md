| 项目 | 检查与结果 |
| --- | --- |

| 门、楼梯、沙发与壁炉 | 已查看；门框画布放宽至 48×64，避免门洞缩小。入口碰撞与换图尚未接入。 |

| 职业书桌与生活装饰 | 已查看；人物职业通过育苗、钟表、地图、信件、戏服等陈设区分。落地酒柜分类为家具。 |
| 地毯与墙地纹理 | 已查看；墙面含墙纸、木护墙及上下收边；木地板和石地板已检查重复铺设。统一调色板补充石材灰阶。 |
| 文件与规格 | 全部 40 项通过尺寸、文件哈希、硬透明边缘、共享调色板检查。家具与地毯保留透明区域；源图尺寸核对通过。 |
| 纹理重复 | 木地板、石地板上下左右边界像素一致；墙面左右边界一致。镜像加工会产生重复纹样，铺大面积时仍需场景层的变体和遮挡设计。 |
| 生成客户端 | 模拟查询超时后仍查询同一任务，不再次提交；任务编号落盘；鉴权失败立即退出。 |
| 代码检查 | 新增生成、规格和检查脚本及修改的客户端通过 Ruff lint/format 检查。 |
